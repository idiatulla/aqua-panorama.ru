# aqua-panorama.ru

Статическая HTML-версия сайта https://aqua-panorama.ru («Аква-Панорама», художественный салон, Казань), бывший WordPress.

```
index.html, portfolio/<раздел>/index.html, author/…   страницы
assets/images   изображения
assets/css      стили (в т.ч. fonts.css — локальный шрифт Philosopher)
assets/js       скрипты
assets/fonts    шрифты (Philosopher, woff2: кириллица + латиница)
assets/files    PDF
```

Форма обратной связи и форма комментариев удалены (на статике они не работают).
